## Classification algorithms for bees at the entrance to the hive to predict their trajectory.

### FILES

month\_data/5second -> Tracking bee movements from subset of month-long data by merging tracks of the same bee with a difference of <5 seconds.

month\_data/20second -> Same as prior, with <20 second merging instead.

month\_data/60second -> Same as prior, with <60 second merging instead.

month\_data/bees -> All 289 csv data with text files containing their names to combine them.

month\_data/\*.csv -> Manual annotation for subset data.
